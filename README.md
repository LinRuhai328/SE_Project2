## 设计要点

- **成员关系独立成实体**：角色会变、退出后要留历史，因此不把角色写成账本上的字段。
- **六个状态互斥且转换受控**：草稿、待审核、已审核、已驳回、已撤回、已作废；任何状态不得回退到草稿。
- **结算结果冻结为快照**：重开账期后旧快照保留为历史版本，历史报表不随明细改动而变化。
- **写路径统一入口**：新增、更正、作废、结算共用一套状态机与权限判定，避免“页面能点、服务端拒绝”。
